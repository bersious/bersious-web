# bersious.io.vn

Trang web cá nhân chính thức của **bersious** — tên miền `bersious.io.vn`.

> 🚀 **Xem trang web trực tiếp:** [**bersious.io.vn (beta)**](https://bersious.io.vn)

## Tổng quan

Đây là mã nguồn của trang web `bersious.io.vn`, chạy trên hạ tầng Vercel và mã nguồn được quản lý trên GitHub. Mỗi lần có thay đổi được đẩy lên nhánh `main`, Vercel sẽ tự động triển khai phiên bản mới.

## Cấu trúc

```
bersious-web/
├── index.html      # Trang chính
└── README.md
```

## Công nghệ

- **HTML / CSS / JavaScript** thuần — không framework, không cần build.
- **Vercel** — hosting tĩnh, tự động HTTPS.
- **GitHub** — lưu trữ mã nguồn và kích hoạt auto-deploy.

## Phát triển & Triển khai

### Xem trước cục bộ

Mở file `index.html` trực tiếp bằng trình duyệt là xem được ngay.

### Cập nhật nội dung

Chỉ cần sửa `index.html`, commit và push lên nhánh `main`:

```bash
git add index.html
git commit -m "Nội dung cập nhật"
git push origin main
```

Vercel sẽ tự động cập nhật trang web trong vài giây mà không cần thao tác thêm.
